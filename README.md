# Project-Landing-page-effectiveness-for-subscriber-growth-MoSPI-Gov

# Aim of the Project

•	To analyze the effectiveness of a new landing page in increasing user engagement and subscriber growth using A/B testing methodology.

# Objective of the Project

•	To compare user behavior between old (control group) and new (treatment group) landing pages.
•	To measure differences in:
o	Time spent on the page
o	Conversion rate (subscriber sign-up behavior)
•	To determine whether the new landing page significantly improves user engagement and conversions.
•	To validate results using statistical hypothesis testing.

# Core of the Project
•	A/B testing framework applied on two groups:
o	Control group → Old landing page
o	Treatment group → New landing page
•	Dataset of 100 users with attributes:
o	group, landing_page, time_spent_on_the_page, converted, language_preferred

# Core analysis includes:
o	Exploratory Data Analysis (EDA)
o	Descriptive statistics
o	Visualization (histograms, KDE plots)
o	Hypothesis testing (mean comparison & conversion analysis)

# Tools Used in the Project
•	Python
•	Pandas (data handling & analysis)
•	NumPy (numerical computation)
•	Seaborn (data visualization)
•	Matplotlib (plotting graphs)
•	SciPy (statistical hypothesis testing)
•	Jupyter Notebook (execution environment)

# Benefits of the Project
•	Helps improve subscriber conversion through data-driven decisions.
•	Identifies which landing page performs better for user engagement.
•	Reduces guesswork in marketing/design decisions.
•	Improves customer experience by optimizing page design.
•	Enables evidence-based product improvements.

# Advantages & Disadvantages

# Advantages

•	Data-driven A/B testing approach ensures reliable decision-making.
•	Simple experimental design (control vs treatment).
•	Easy to interpret results using statistical tests.
•	Helps optimize digital marketing performance.

# Disadvantages

•	External factors (user intent, device type, traffic source) are not included.
•	Short-term experiment may not reflect long-term behavior.
•	Only one variation (old vs new page) tested, limiting scope.

# Result & Outcome

•	Statistical testing shows:
o	New landing page increases time spent on the page.
o	Conversion rate is higher for the new landing page.
o	Some statistical tests confirm significant improvement (based on p-values shown in notebook).

# Final outcome:

o	The new landing page is more effective than the old one in improving engagement and subscriber conversion.

# Business conclusion:

o	The company can consider deploying the new landing page for better subscriber growth.
